# 0009: Hybrid Canva Presentation Links and Multi-Format Deck Uploads

Canva presentation integration requires an official Canva Connect App for OAuth 2.0 flows, and trainers frequently bring slide decks in offline formats (PDF, image slides, or PPTX). We decided to build a hybrid presentation model supporting full-deck Canva embed links alongside direct multi-format presentation uploads (`PDF`, `IMAGES`, `PPTX`) stored in session configuration. This eliminates mandatory per-slide checkpoint binding, allows facilitators to project and replace decks at any time, and guarantees zero-dependency operation across both cloud-hosted Canva designs and local presentation files.
